Testing and Quality Assurance

Project Overview

This project is a simple Java calculator developed for learning software testing and quality assurance.

Technologies Used

- Java
- GitHub

Project Files

- "Calculator.java" — Contains the calculator operations.
- "CalculatorTest.java" — Contains test cases for checking the calculator operations.

Testing Objectives

- To test addition, subtraction, multiplication, and division.
- To check the division-by-zero error.
- To identify errors and improve software reliability.

Conclusion

This project demonstrates basic software testing concepts using a Java program and simple test cases.
